## Project 1 · 카운터 앱

React와 Vite로 만든 학습용 카운터 앱입니다. 숫자를 바꾸는 기능을 만들며 state, props, 컴포넌트의 라이프 사이클을 익힙니다.

### 주요 기능

- 버튼을 눌러 카운트를 1, 10, 100씩 더하거나 뺍니다.
- 카운트가 짝수일 때 안내 문구를 표시합니다.
- 텍스트 입력과 버튼 클릭으로 state 변경을 연습합니다.

### 컴포넌트 구성

| 컴포넌트 | 역할 |
| --- | --- |
| `App` | 카운트와 입력값을 관리하고 자식 컴포넌트에 전달합니다. |
| `Viewer` | 현재 카운트를 보여줍니다. |
| `Controller` | 카운트를 변경하는 버튼을 제공합니다. |
| `Even` | 카운트가 짝수일 때 표시됩니다. |

### 학습 내용

- **UI 구성**: 화면을 컴포넌트로 나누고 CSS로 꾸밉니다.
- **State와 이벤트**: `useState`로 값을 저장하고 입력이나 클릭으로 변경합니다.
- **Props와 state 끌어올리기**: 함께 쓰는 카운트를 부모인 `App`에서 관리하고, 값과 변경 함수를 자식에게 전달합니다.
- **조건부 렌더링**: 카운트가 짝수일 때만 `Even`을 표시합니다.
- **라이프 사이클**: `useEffect`로 마운트(처음 표시), 업데이트(다시 렌더링), 언마운트(화면에서 제거)를 확인합니다.
- **Ref와 클린업**: `useRef`로 첫 실행 여부를 기억하고, 클린업 함수로 `Even`이 사라질 때 로그를 남깁니다.

버튼 클릭 → `App`의 state 변경 → `Viewer`에 새 카운트 표시

## Project 2 · 할 일 관리 앱

React와 Vite로 만든 학습용 할 일 관리 앱입니다. 할 일 추가·검색·완료 상태 변경·삭제 기능을 구현하고, 상태 관리와 최적화, Context를 활용한 데이터 전달을 익힙니다.

### 주요 기능

- 오늘 날짜와 할 일 목록을 표시합니다.
- 추가 버튼이나 Enter 키로 새로운 할 일을 등록합니다.
- 빈 입력은 등록하지 않고 입력창에 포커스를 이동합니다.
- 검색어가 포함된 할 일을 대소문자 구분 없이 찾습니다.
- 체크박스로 완료·미완료 상태를 변경하고, 삭제 버튼으로 할 일을 제거합니다.
- 전체·완료·미완료 할 일 개수를 표시합니다.

### 컴포넌트 구성

| 컴포넌트 | 역할 |
| --- | --- |
| `App` | 할 일 상태를 관리하고 Context로 데이터와 변경 함수를 공급합니다. |
| `Header` | 오늘 날짜를 보여줍니다. |
| `TodoEditor` | 입력값을 관리하고 새로운 할 일을 등록합니다. |
| `TodoList` | 할 일 목록과 검색창, 통계를 보여줍니다. |
| `TodoItem` | 개별 할 일의 내용과 생성 날짜를 표시하고, 완료 상태 변경과 삭제를 처리합니다. |
| `TestComp` | `useReducer`로 숫자 증가·감소·초기화를 연습합니다. |

### 학습 내용

- **UI 구성**: 화면을 역할별 컴포넌트로 나누고 CSS로 꾸밉니다.
- **데이터 모델링**: 할 일을 ID, 내용, 완료 여부, 생성 날짜를 가진 객체로 만들고 배열로 관리합니다.
- **State와 Props**: `useState`로 상태를 관리하고, 부모에서 자식으로 데이터와 함수를 전달합니다.
- **Ref와 입력 처리**: `useRef`로 고유 ID를 관리하고 빈 입력 시 입력창에 포커스를 이동합니다.
- **배열과 CRUD**: 전개 구문, `map`, `filter`로 할 일 추가·조회·완료 상태 변경·삭제를 구현합니다.
- **useReducer**: 상태 변경 로직을 reducer에 모으고, `dispatch`로 추가·변경·삭제 요청을 전달합니다.
- **useMemo**: 할 일 통계의 계산 결과를 재사용해 불필요한 재계산을 줄입니다.
- **React.memo와 useCallback**: 컴포넌트의 불필요한 리렌더링을 줄이고, 변경·삭제 함수의 참조를 유지합니다.
- **Context**: 목록과 변경 함수를 별도의 Context로 공급하고, 필요한 컴포넌트에서 `useContext`로 사용합니다.

UI 구성 → CRUD와 검색 구현 → useReducer로 상태 관리 정리 → 메모이제이션 최적화 → Context로 데이터 전달 구조 개선
