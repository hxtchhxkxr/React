## Project 1 · 카운터 앱

React와 Vite로 만든 학습용 카운터 앱입니다. 숫자를 바꾸는 기능을 만들며 state, props, 컴포넌트의 라이프 사이클을 익힙니다.

### 주요 기능

- 버튼을 눌러 카운트를 1, 10, 100씩 더하거나 뺍니다.
- 카운트가 짝수일 때 안내 문구를 표시합니다.
- 텍스트 입력과 버튼 클릭으로 state 변경을 연습합니다.

### 컴포넌트 구성

| 컴포넌트 | 역할 |
| --- | --- |
| `App` | 카운트와 입력값을 관리하고 자식 컴포넌트에 전달합니다. |
| `Viewer` | 현재 카운트를 보여줍니다. |
| `Controller` | 카운트를 변경하는 버튼을 제공합니다. |
| `Even` | 카운트가 짝수일 때 표시됩니다. |

### 학습 내용

- **UI 구성**: 화면을 컴포넌트로 나누고 CSS로 꾸밉니다.
- **State와 이벤트**: `useState`로 값을 저장하고 입력이나 클릭으로 변경합니다.
- **Props와 state 끌어올리기**: 함께 쓰는 카운트를 부모인 `App`에서 관리하고, 값과 변경 함수를 자식에게 전달합니다.
- **조건부 렌더링**: 카운트가 짝수일 때만 `Even`을 표시합니다.
- **라이프 사이클**: `useEffect`로 마운트(처음 표시), 업데이트(다시 렌더링), 언마운트(화면에서 제거)를 확인합니다.
- **Ref와 클린업**: `useRef`로 첫 실행 여부를 기억하고, 클린업 함수로 `Even`이 사라질 때 로그를 남깁니다.

버튼 클릭 → `App`의 state 변경 → `Viewer`에 새 카운트 표시

## Project 2 · 할 일 관리 앱

React와 Vite로 만든 학습용 할 일 관리 앱입니다. 할 일 추가·검색·완료 상태 변경·삭제 기능을 구현하고, 상태 관리와 최적화, Context를 활용한 데이터 전달을 익힙니다.

### 주요 기능

- 오늘 날짜와 할 일 목록을 표시합니다.
- 추가 버튼이나 Enter 키로 새로운 할 일을 등록합니다.
- 빈 입력은 등록하지 않고 입력창에 포커스를 이동합니다.
- 검색어가 포함된 할 일을 대소문자 구분 없이 찾습니다.
- 체크박스로 완료·미완료 상태를 변경하고, 삭제 버튼으로 할 일을 제거합니다.
- 전체·완료·미완료 할 일 개수를 표시합니다.

### 컴포넌트 구성

| 컴포넌트 | 역할 |
| --- | --- |
| `App` | 할 일 상태를 관리하고 Context로 데이터와 변경 함수를 공급합니다. |
| `Header` | 오늘 날짜를 보여줍니다. |
| `TodoEditor` | 입력값을 관리하고 새로운 할 일을 등록합니다. |
| `TodoList` | 할 일 목록과 검색창, 통계를 보여줍니다. |
| `TodoItem` | 개별 할 일의 내용과 생성 날짜를 표시하고, 완료 상태 변경과 삭제를 처리합니다. |
| `TestComp` | `useReducer`로 숫자 증가·감소·초기화를 연습합니다. |

### 학습 내용

- **UI 구성**: 화면을 역할별 컴포넌트로 나누고 CSS로 꾸밉니다.
- **데이터 모델링**: 할 일을 ID, 내용, 완료 여부, 생성 날짜를 가진 객체로 만들고 배열로 관리합니다.
- **State와 Props**: `useState`로 상태를 관리하고, 부모에서 자식으로 데이터와 함수를 전달합니다.
- **Ref와 입력 처리**: `useRef`로 고유 ID를 관리하고 빈 입력 시 입력창에 포커스를 이동합니다.
- **배열과 CRUD**: 전개 구문, `map`, `filter`로 할 일 추가·조회·완료 상태 변경·삭제를 구현합니다.
- **useReducer**: 상태 변경 로직을 reducer에 모으고, `dispatch`로 추가·변경·삭제 요청을 전달합니다.
- **useMemo**: 할 일 통계의 계산 결과를 재사용해 불필요한 재계산을 줄입니다.
- **React.memo와 useCallback**: 컴포넌트의 불필요한 리렌더링을 줄이고, 변경·삭제 함수의 참조를 유지합니다.
- **Context**: 목록과 변경 함수를 별도의 Context로 공급하고, 필요한 컴포넌트에서 `useContext`로 사용합니다.

UI 구성 → CRUD와 검색 구현 → useReducer로 상태 관리 정리 → 메모이제이션 최적화 → Context로 데이터 전달 구조 개선

## Project 3 · 감정 일기장

React와 Vite로 만든 학습용 감정 일기장입니다. 날짜와 감정을 담은 일기를 작성·조회·수정·삭제하고, 페이지 라우팅과 공통 컴포넌트, Context를 활용한 상태 관리와 렌더링 최적화를 익힙니다.

### 주요 기능

- 이전 달과 다음 달로 이동하며 해당 월의 일기 목록을 확인합니다.
- 일기를 날짜 기준으로 최신순 또는 오래된 순으로 정렬합니다.
- 날짜, 다섯 가지 감정 중 하나, 내용을 입력해 새 일기를 작성합니다.
- 목록에서 감정 이미지, 날짜, 내용 미리보기를 표시하고 상세 페이지로 이동합니다.
- 상세 페이지에서 일기의 날짜와 감정, 전체 내용을 확인합니다.
- 기존 일기를 편집기에 불러오고, 확인창을 통해 수정하거나 삭제합니다.
- 일기 데이터를 불러오는 동안 안내 문구를 표시하고, 없는 일기에 접근하면 알림 후 홈으로 이동합니다.

### 컴포넌트 구성

| 컴포넌트 | 역할 |
| --- | --- |
| `App` | 일기 상태와 라우팅을 관리하고 Context로 데이터와 변경 함수를 공급합니다. |
| `Home` | 선택한 월을 표시하고 해당 월의 일기를 걸러 목록에 전달합니다. |
| `New` | 새 일기 작성 화면을 구성하고 입력한 데이터로 일기를 생성합니다. |
| `Diary` | URL의 ID에 해당하는 일기를 불러와 상세 내용을 보여줍니다. |
| `Edit` | 기존 일기를 편집기에 전달하고 수정·삭제를 처리합니다. |
| `Button` | 문구, 유형별 스타일, 클릭 동작을 전달받는 공통 버튼입니다. |
| `Header` | 페이지 제목과 좌우 버튼 영역을 구성하는 공통 헤더입니다. |
| `Editor` | 날짜·감정·내용 입력과 제출·취소를 처리하며, 작성과 수정 화면에서 함께 사용합니다. |
| `EmotionItem` | 감정 이미지와 이름을 표시하고 감정 선택 및 선택 상태 표시를 담당합니다. |
| `DiaryList` | 정렬 선택, 새 일기 작성 버튼, 일기 목록을 보여줍니다. |
| `DiaryItem` | 개별 일기의 미리보기를 표시하고 상세·수정 페이지로 이동합니다. |
| `Viewer` | 일기의 감정 이미지와 이름, 전체 내용을 보여줍니다. |

### 학습 내용

- **프로젝트 준비와 공통 스타일**: 폰트와 감정 이미지를 적용하고 화면 너비, 배경, 여백을 설정합니다.
- **페이지 라우팅**: `BrowserRouter`, `Routes`, `Route`로 홈·작성·상세·수정 페이지를 나누고 `useNavigate`로 이동합니다.
- **동적 경로**: `/diary/:id`, `/edit/:id`를 설정하고 `useParams`로 일기 ID를 가져옵니다.
- **공통 컴포넌트와 Props**: Button과 Header를 재사용하고, Editor에 초기 데이터와 제출 함수를 전달해 작성·수정 화면을 구성합니다.
- **State와 입력 처리**: `useState`로 날짜·감정·내용을 관리하고 입력 이벤트를 상태에 반영합니다.
- **데이터 모델링과 CRUD**: 일기를 ID, 날짜, 감정 ID, 내용을 가진 객체로 만들고 전개 구문, `map`, `filter`로 추가·조회·수정·삭제합니다.
- **useReducer와 Ref**: reducer에 초기화·생성·수정·삭제 로직을 모으고, `useRef`로 새 일기의 ID를 관리합니다.
- **Context**: 일기 데이터와 변경 함수를 별도의 Context로 공급하고, 필요한 곳에서 `useContext`로 사용합니다.
- **날짜 처리와 목록 구성**: 날짜 형식을 변환하고 월별 범위로 일기를 필터링하며, 배열을 복사한 뒤 날짜순으로 정렬합니다.
- **커스텀 Hook과 조건부 렌더링**: `useDiary`로 일기 조회와 없는 일기 처리를 재사용하고, 데이터가 준비되기 전에는 로딩 문구를 표시합니다.
- **React.memo와 useCallback**: DiaryItem과 EmotionItem에 `React.memo`를 적용하고, 감정 변경 함수는 `useCallback`과 함수형 상태 업데이트로 참조를 유지해 불필요한 리렌더링을 줄입니다.

프로젝트 준비 → 페이지 라우팅 → 공통 컴포넌트와 스타일 → 일기 상태 관리 → Home·Diary·New·Edit 구현 → 렌더링 최적화

### 현재 구현 범위

책 목차의 **최적화** 단계까지 구현했습니다. 현재 일기는 메모리의 state로 관리하므로 새로고침하면 목 데이터로 초기화됩니다. 웹 스토리지를 이용한 데이터 보관과 배포는 이후 학습 단계입니다.
